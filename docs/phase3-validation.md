# 第三阶段验收

在「记忆库」登记锁定设定和知情范围，在「场景微调」绑定视角人物。正式修订保存后，正文可按连续汉字检索，设定可按名称或别名精确查找。在写作台右侧的「审查」点击「完成本章」分别运行一致性审查和证据提取。为这两个角色保存可用模型后，AI 草稿采纳达到目标字数也会触发两项独立任务。

提取候选按正式修订的 UTF‑16 原文位置校验。确切的普通事件可以自动入库和撤回。死亡、秘密、关系变化、不可逆事件、低置信及与锁定设定重叠的候选需要确认。自动入库的记录默认由作者查看。作者可为记录配置视角权限、可观察线索，或记录人物误信、怀疑及得知真相的起点。

写作模型只接收视角可见的设定、事实、摘要、叙事备注和可观察线索。含有受限记录时，默认省略未经范围标注的旧稿、历史提示词覆写和原始场景字段。作者搜索可查看原文命中，写作检索只使用匹配章节定位已完成同一权限检查的事实。一致性审查读取需要核对的全知资料，告警定位正式修订中的原句。

| 验收项目 | 本机结果 |
| --- | --- |
| 调包账本的对抗测试 | 冻结请求逐项排除 Canon 秘密、事件、章节摘要、关联备注、正文、续写草稿和提示词覆写中的秘密，保留两条可观察线索。额外覆盖标点变形和怀疑、误信、真知 |
| 一百万汉字以上的 SQLite FTS5 检索 | 100 章共 110 万汉字，99 个标点分隔的伪命中均被排除。一次首次查询 0.535 毫秒，80 次查询中位 0.183 毫秒，第 95 百分位 0.310 毫秒。计时包含本机 SQLite 查询与命中摘要构造 |
| 证据覆盖率 | 测试中所有入库事实均有字面原文锚点。伪造偏移拒绝，包含 Unicode 代理对的原文按 UTF‑16 校验。已确认事件与撤回状态经文件重开仍存在 |
| 两路任务隔离 | 提取与审查分别创建和持久化。原生数据库拒绝把审查任务作为提取候选来源 |
