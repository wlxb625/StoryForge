# 第四阶段验收

「大纲」允许作者给章节分配阶段，并维护阶段目标、预计章数和里程碑。改纲时先检查旧伏笔与备注，确认后保存新目标和零到多章的过渡说明。建议章数来自未完成路标和开放备注，作者可调整。将大纲提供给主笔需在该阶段勾选，提供前会执行视角过滤。

保存正式修订时可以选择字词与排版、情节与含义、设定变更。排版和标点变化默认建议字词与排版。作者可以把经过判断的错别字修正归入同级。字词与排版保留同步状态。情节与含义调用本地 FTS5，按涉及的已登记名称、别名或作者填写词语提示后续章节。重要正史事件的原文被改动时需要确认。仍能准确匹配的证据锚点重新定位，无法定位的证据保留在旧修订。

写作台右侧「编辑」可以对已保存的选区生成局部精修，带前后各 500 字语境。差异展示删除和加入的逐字符片段。采用时再次校验正式修订、正文哈希、原文和选区偏移，冲突返回 409。「请主编挑刺」按需触发并呈现有逐字引文的阅读建议。

| 验收项目 | 本机结果 |
| --- | --- |
| 第五章将铜匙从留在北门改为交给周宁 | FTS5 找到第六章证据，原第六章修订 ID、修订数量和正文均保持一致 |
| 第五章修正一个错别字 | 生成正式修订，记忆仍为已同步且版本计数保持一致 |
| 选区竞争与差异 | 表情符号按 UTF‑16 边界验证，变更正文、修改选区、再次采用过期建议均返回 409 |
| 改纲两步确认 | 根据旧阶段预览得出建议，保存过渡章数和说明后可重新打开，重复使用旧预览返回 409 |
