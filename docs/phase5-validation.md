# 第五阶段交付与验收

## Windows 使用

安装包面向 Windows x64。便携版解压到可写目录后运行 `StoryForge.exe`，需要 Microsoft Edge WebView2 Runtime。便携版的模型档案保存在随程序的 `settings` 目录。API 密钥继续保存在 Windows 凭据管理器，换电脑后通过应用内的系统凭据窗口重新设置。安装与便携版可通过 `scripts/package-windows.ps1` 重建。

在「全景」可查看和编辑 SQLite 中的人物 Markdown 状态卡，并查看道具交接、事件时间线、人物关系及伏笔回收情况。导出支持工程快照、DOCX 和 EPUB。工程快照由 SQLite Online Backup 生成，写入前检查完整性以及数据库字段和文件字节中的凭据。DOCX 和 EPUB 读取已采纳的正式正文。

## 后台连写

选择待写的章节、预算和有单价的主笔、审查、提取模型。确认允许自动保存后，后台按章节顺序生成节拍，并在达到字数时执行两路独立审查与提取。关闭主窗口会隐藏到托盘，退出应用停止进程。重新打开工程可以恢复未结束的批次。

下一请求发送前需要满足预算预留。系统优先使用提供方报告的费用。仅返回 token 用量时按已配置价格的上限估算。缺少用量或请求状态不明时，按本次预留记账并暂停。命中重大告警、需要审核的事件、缺失证据或预算不足时，批次会停在对应步骤。

## 需独立完成的外部验收

项目契约要求多台纯净 Windows 机验证，并由一位未参与开发的人在 10 分钟内完成模型配置、导入配方和前三章写作。当前只有本机执行环境，这两项仍待独立验证。安装包的证书签名需使用发布者持有的代码签名证书。

## 本机实测

- 原生 Windows 写作台打开了第二阶段的工程副本并迁移到版本 5，原正式修订 ID 保留。后台预算过低时未发送请求。提高预算并关闭窗口到托盘后，三章连写完成并同步记忆。本机验收服务收到 9 次续写、3 次审查与 3 次证据提取请求。这些请求使用本机测试服务。
- 从应用导出了含四章正文的快照、DOCX 和 EPUB。快照在新连接上通过 SQLite 完整性检查。Word 只读打开导出的 DOCX，确认末章标题。EPUB 中的容器、目录、清单和四章 XHTML 解析通过，并检查了 ZIP 内首项的压缩设置。
- 原生测试覆盖预算预留、费用结算的幂等性、远端结果未知、严重冲突暂停、快照中的敏感字段检查以及旧库迁移。100 章合成语料用于 FTS5 检索验收和写作提示词的记忆上限回归。
- 最终构建通过 14 项前端测试和 15 项原生测试。独立原生运行的 110 万汉字检索首次查询 0.570 毫秒，中位 0.164 毫秒，第 95 百分位 0.452 毫秒。
- 在本机 Windows 11 x64 启动了便携版和 NSIS 安装的应用，两者均打开写作台窗口。安装验收使用临时目录，卸载后注册表项已清除。安装程序的 Authenticode 状态为未签名。
